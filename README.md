# EVEZ Proofs: External Confirmation Ledger

This repository records requests for independent confirmation of specific records concerning Steven Crawford-Maggard.

It does not presume that an allegation is true. It records what was requested, what source could independently answer it, and what response was received.

## Status vocabulary

- REQUESTED: a confirmation request was sent.
- ACKNOWLEDGED: the recipient confirms receipt.
- CONFIRMED: the recipient independently confirms the underlying record or event.
- DENIED: the recipient expressly denies the requested fact.
- PARTIAL: only part of the requested record was confirmed.
- NO_RESPONSE: no response by the stated deadline.
- UNKNOWN: evidence is insufficient to classify the matter.

## Identity requirement

Where a request concerns Steven Crawford-Maggard, the requested confirmation should identify the relevant record using the recipient's own identifier and the exact name supplied to that recipient. No identity linkage is inferred merely from a similar name.

## Evidence rule

A company response is evidence of what the company states. It is not automatically proof of every interpretation attached to that response.

Every preserved response should include:
- recipient
- date/time
- request text
- response text
- source URL or message identifier
- attachment hashes where applicable
- EventSpine event hash where available
